## 5. Residual risk and GC follow-up

Orphan git objects remain accessible via direct SHA fetch :
  gh api repos/roastercode/beamfs/commits/62dbb4697b...
  gh api repos/roastercode/beamfs/git/blobs/<blob-sha>

These SHAs are not discoverable through standard API endpoints (branch list, contents API, search). Discovery requires prior knowledge of the exact 40-char hash.

GitHub GC runs every 7 to 14 days on average. After GC, the orphan objects become unfetchable. To force immediate GC, two options exist :
1. Contact GitHub support (1 to 2 days response).
2. Delete and recreate the PUBLIC repository entirely (loses stars, watchers, URL history, fork graph).

Decision (2026-05-15) : no forced GC. Rationale : 0 fork, 0 star, 0 watcher means no realistic external party knows the SHAs to query. Wait for natural GC.

## 7. Root cause analysis

Two pushes (2026-05-06 15:16 and 18:37) authored by roastercode targeted PUBLIC origin instead of PRIVATE private. The R14 rule existed at the time but was not enforced by tooling, only by procedure. The exact git invocation that produced the leak is unknown.

Hypothesis 1 : a session executed git push origin devel verbatim, possibly under the assumption that origin was the private remote (which it is NOT for beamfs ; convention is inverted, origin = PUBLIC, private = beamfs-devel PRIVATE).

Hypothesis 2 : a tab-completion or shell-history replay produced an incorrect remote name.

Hypothesis 3 : a Claude session generated a bloc that defaulted to origin without R14 visibility check.

Regardless of root cause, the procedure-only enforcement of R14 has now failed twice in 6 days. Tooling enforcement is therefore added : see R39 in context-recadrage.md and the pre-push-hook.sh script in this directory.

## 8. Prevention going forward

See new rule R39 in context-recadrage.md. Summary :
- pre-push hook (context/pre-push-hook.sh) installed in every beamfs clone's .git/hooks/pre-push, refuses push to origin for any branch other than main.
- explicit remote naming required in all blocs : git push private devel (never git push devel, never git push origin devel for non-main branches).
- mandatory pre-push gh repo view visibility check is now a pre-push hook step, not just a procedure.
